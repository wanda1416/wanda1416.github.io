# 律匠 0.6.0 教程视频制作总纲

本目录包含两支教程的可执行拍摄稿：

1. `01-入门连接扫描与毕业率-完整脚本.md`
2. `02-自动调律与规则设置-完整脚本.md`

两支视频都以 Windows 发行版 **律匠 0.6.0** 为准。不要展示 `dev_0.7.0`
中的脚本录制增强，也不要混用源码版界面。

## 一、成片定位

### 视频一

- 受众：第一次使用律匠的用户。
- 核心承诺：看完能够连接 PC 端游或安卓设备，完成装备扫描，并得到可信的
  DPS 与毕业率。
- 建议成片长度：14～17 分钟。
- 叙事主线：连接成功 → 数据产生 → 结果出现。

### 视频二

- 受众：已经完成连接，准备使用自动调律的用户。
- 核心承诺：看完能够理解“规则判定”和“行为处置”的区别，安全地配置并
  执行一次指定装备调律。
- 建议成片长度：20～25 分钟。
- 叙事主线：理解决策模型 → 配置规则 → 验证 → 小范围实跑 → 查报告。

## 二、统一录制规格

- 桌面分辨率：1920×1080。
- Windows 显示缩放：100%。
- OBS 画布与输出：1920×1080，60 FPS；机器性能不足时可用 30 FPS。
- 编码：H.264，画质优先，关键帧间隔 2 秒。
- 音频：48 kHz；麦克风与桌面声音分轨。
- 鼠标：关闭无关轨迹特效；后期统一添加黄色圆圈或方框强调。
- 字幕：白字加深色描边；风险提示使用橙色，禁止/不可恢复使用红色。
- 字号：1080p 成片中正文不低于 40 px，角标不低于 32 px。

建议先完成全部无声画面录制，再按脚本录制旁白。这样可以根据实际操作耗时
调整语速，也能避免一边操作一边口误。

## 三、录制源与场景

OBS 建议建立以下场景：

| 场景名 | 内容 |
|---|---|
| `LVJ-全窗口` | 只捕获律匠窗口，不录整个桌面 |
| `GAME-PC` | PC 端游戏窗口 |
| `PHONE-ADB` | 手机画面或投屏窗口 |
| `LVJ+GAME` | 左侧律匠，右侧游戏，适合演示自动操作 |
| `WEB-RELEASE` | 浏览器中的 GitHub Releases 页面 |
| `WIN-SETTING` | Windows 安装、管理员启动、文件目录 |
| `PHONE-SETTING` | 手机开发者选项、USB 调试和授权弹窗 |
| `TITLE` | 章节标题卡 |

不要使用“显示器捕获”长期录制，避免聊天消息、密码管理器、设备序列号和私人
文件意外入镜。

## 四、必须准备的测试数据

### 通用

- 律匠 0.6.0 安装版与便携版各一份。
- 一个可公开展示的测试角色，名称无隐私风险。
- 游戏画面使用固定分辨率，不在录制过程中改变窗口大小。
- `config/session` 与 `config/local` 的完整备份。
- 一份干净配置，用于拍摄首次启动和默认界面。
- 一份已有装备数据的配置，用于快速补拍毕业率和调律结果。

### 视频一

- PC 端游窗口，1920×1080 窗口模式。
- 一台已开启 USB 调试的安卓手机，或一台可稳定连接的模拟器。
- 手机使用接近 20:9 的游戏分辨率。
- 背包中各部位至少有一件 110 级装备，但不要多到扫描耗时失控。
- 当前穿戴八件装备完整。
- 游戏角色最终属性面板的数据提前抄在纸面或文本文件中。
- 已导入并可选择的对应流派毕业率方案。

### 视频二

- 足够的大律准石和必要狗粮。
- 一件允许被调律、重置或回收的测试装备。
- 提前记下该装备在背包中的行列位置。
- 准备一件词条组合容易解释的装备，用于“装备调律验证”。
- 调律配置先恢复到 0.6.0 默认值，再复制备份。

## 五、隐私和安全检查

录制前逐项检查：

- 隐藏真实账号、手机号、登录二维码和支付信息。
- 手机 ADB serial、局域网 IP、Windows 用户名需要打码。
- 关闭微信、QQ、邮件、浏览器推送和系统通知。
- 游戏聊天频道切到不会显示私人消息的频道。
- 日志中的本地绝对路径若包含真实姓名，后期打码。
- 调律实拍只使用可损失的测试装备。
- 录制调律前再次备份 `config/session` 和 `config/local`。

## 六、统一剪辑语言

- 点击普通按钮：黄色框，停留 0.5 秒。
- 当前选择项：绿色框。
- 风险选项：红色框，并显示“可能回收装备”。
- 快进扫描：右上角显示 `×6`，保留首件识别和最终完成为原速。
- 日志说明：暂停画面，放大日志行到屏幕宽度的 70%。
- 路径和快捷键：使用屏幕下方半透明字幕条。
- 每章开头使用 1 秒标题卡，不使用过长转场。

## 七、需要单独录制的通用补镜

这些镜头两支视频都可能使用，每段录制 8～12 秒：

1. 律匠 0.6.0 关于/版本信息。
2. 右键 `lvjiang.exe`，选择“以管理员身份运行”。
3. 顶部环境、布局、图库空间三个位置的特写。
4. 连接成功后的绿色状态文字。
5. 红色定位边框与运行中的绿色边框。
6. 显示预览展开、收起。
7. F9 开始、F8 暂停、F10 停止的按钮变化。
8. 运行日志产生新行。
9. `logs/crashes`、`logs/tuning` 目录，但不要打开含隐私的真实日志。
10. `config/session`、`config/local` 备份操作。

## 八、发布前审片检查

- 视频中所有按钮名称均与 0.6.0 一致。
- 没有把“环境”与“连接方式”混为一谈。
- 没有声称“扫描全部装备”会自动建立当前穿戴方案。
- 没有把单件装备规则评级说成毕业率。
- 没有把“跳过实际调律”说成完整安全沙盒。
- 没有说 0.6.0 只有五条预置调律规则；实际启用的是七条。
- 毕业率演示时三个满值假设开关均已关闭。
- 调律演示明确说明回收不可恢复。
- 简介中附项目 Release、用户指南与问题反馈入口。
